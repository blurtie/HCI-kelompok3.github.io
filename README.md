# HCI Kelompok 3 — Discord Mobile Redesign

Static front-end redesign of the Discord mobile app UI, built for a Human-Computer Interaction course assignment. Pure HTML/CSS/JavaScript, no framework or build step.

## Pages

- `index.html` / `home-discord.html` — Home / server list screen
- `message.html` — Direct messages screen
- `profile.html` / `discord.html` — Profile UI
- `scanqr.html` — QR code scan screen

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Cara Menjalankan

Buka salah satu file `.html` langsung di browser, atau serve dengan static server, contoh:

```bash
npx serve .
```
